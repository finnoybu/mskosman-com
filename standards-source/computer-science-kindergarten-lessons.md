# Kindergarten Computer Science lessons

Standards text quoted in each lesson is pulled verbatim from `standards-source/computer-science-kindergarten-2024.md`.

## Notes

- Lesson files are in `src/content/lessons/`, named `computer-science-k-NN-<slug>.mdx`.
- `solCodes` in frontmatter holds standard-level codes (`K.AP.1`). The lettered sub-items each lesson covers are listed at the top of the lesson body.
- `status` is omitted, so the schema default (`draft`) applies.
- Lessons run 15 to 20 minutes. `durationMinutes` equals the sum of the four timed sections.
- Lessons that need preparation open with a `## Prep` section (all except Lesson 1).
- Each lesson carries one of three tags: `unplugged` (11 lessons), `device` (Lessons 6, 8, 9), or `device-optional` (Lesson 15).
