**Standards covered (2024 Virginia Computer Science SOL)**

- **5.AP.2** The student will plan and implement algorithms that consist of sequencing, loops, variables, user input, and nested conditional control structures using a block-based programming language.
  - a. Describe the concept of nested conditional control structure.
  - c. Read, write, and interpret nested conditional control structures: “if-else” and “if-else; if-else" statements.

## Prep

- Write this on paper with indentation: IF it is raining THEN (IF it is cold THEN wear a raincoat and boots ELSE carry an umbrella) ELSE (IF it is cold THEN wear a jacket ELSE wear a T-shirt).

## Warm-up (3 minutes)

Ask, "How do you decide what to wear outside? Is it one question or more than one?"

## Direct Instruction (5 minutes)

- Review if-else: one condition and two branches. This is two-way branching.
- Define nested: "A conditional placed inside a branch of another conditional." The inner question is asked only if the outer one sends you there.
- Trace the prepared example with today's weather. Show that two questions produce four possible outcomes.
- Show how indentation or boxes within boxes make the structure readable.
- Show the chained form: IF score is at least 90 THEN A, ELSE IF at least 80 THEN B, ELSE C.

## Guided Practice (7 minutes)

1. The student traces the weather example for three different kinds of days.
2. Together, write a nested conditional for choosing a snack: hungry or not, then sweet or salty.
3. The student draws it as a decision tree.
4. Read a chained if-else you write and predict its output for three inputs.

## Independent Practice / Quick Check (4 minutes)

The student writes a nested conditional for a situation of their choice, with correct indentation, and interprets a second one you provide for two different inputs.

Look for:
- The student explains that the inner conditional runs only inside one branch.
- The written structure has correct nesting and every branch has an action.
- Interpretations match the logic.

## Differentiation

**For students needing support**
- Draw the decision tree first, then turn it into IF and ELSE lines.
- Use two questions with yes or no answers.

**For students ready for more**
- Nest three levels deep and count the outcomes.
- Rewrite a nested conditional using AND and compare readability.

## Extensions

- Write the rules of a card game as nested conditionals.
- Draw a decision tree for a family routine.

## Notes for Parent/Instructor

- Indentation is not decoration. It shows which condition each action belongs to.
- A decision tree and a nested conditional are the same logic drawn two ways.
