**Standards covered (2024 Virginia Computer Science SOL)**

- **8.AP.2** The student will plan and implement algorithms that include sequencing, loops, variables, user input, conditional control structures, functions, and various data types.
  - a. Describe the concept of input and output of various data types for use in a computer program.
  - b. Plan an algorithm using plain language, pseudocode, or diagrams.

## Prep

- Make a reference list for your tool: integer, decimal, string, Boolean, and list or array, with one example of each.

## Warm-up (3 minutes)

Ask, "A program asks for your age and you type 'thirteen.' What should it do?"

## Direct Instruction (5 minutes)

- Review the data types: integers, decimal numbers, strings, and Booleans. Add lists, which hold many values in order.
- Explain input: data arrives from a user, a file, or a sensor, often as text, and must be converted and checked.
- Explain output: the program presents data as text, numbers formatted for reading, graphics, sound, or a file. The same value can be shown in different forms.
- Explain why types matter: each supports different operations, and mixing them causes errors.
- Model an input and output table for a program: each item, its type, where it comes from, and how it is checked or shown.

## Guided Practice (7 minutes)

1. The student builds the input and output table for their project.
2. For each input, decide what counts as valid.
3. Add the variables and their types to the plan.
4. Update the pseudocode or flowchart to include input checking and output formatting.

## Independent Practice / Quick Check (4 minutes)

The student completes the plan: an input and output table with data types, a variable list, and the algorithm including functions, loops, conditionals, and input checks.

Look for:
- Each input and output has a stated type.
- Validation is planned.
- The plan includes all required structures.

## Differentiation

**For students needing support**
- Plan a program with two inputs and one output.
- Fill in the table together.

**For students ready for more**
- Plan a list that stores many values and a loop that processes it.
- Plan for reading from or writing to a file.

## Extensions

- Examine a form on a website and list the data type of each field.
- Find a real error message caused by the wrong data type.

## Notes for Parent/Instructor

- Input checking is where plans most often have gaps.
- Lists appear here because the standard says various data types.
