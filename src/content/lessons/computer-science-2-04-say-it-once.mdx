**Standards covered (2024 Virginia Computer Science SOL)**

- **2.AP.2** The student will plan and implement algorithms that consists of events and loops using a block-based programming language.
  - b. Identify a section of repeated actions within an algorithm and replace it with a loop.
  - c. Construct step-by-step instructions that include events and repetition.

## Prep

- Write a long algorithm on cards, one action per card: step, clap, step, clap, step, clap, step, clap, bow.
- Make one card that reads REPEAT 4 TIMES and one that reads WHEN THE BELL RINGS.

## Warm-up (3 minutes)

Lay out the nine action cards. Ask the student to act them out. Then ask, "Did you notice anything about these instructions?"

## Direct Instruction (5 minutes)

- Explain: "When the same actions happen again and again, we can write them once and say how many times. That is a loop."
- Circle the repeated section with your finger: step, clap. Count how many times it appears.
- Replace it: REPEAT 4 TIMES: step, clap. Then bow. Show that nine cards became four.
- Ask, "Does the new algorithm do exactly the same thing?" Act it out to check.
- Add the event card in front: WHEN THE BELL RINGS. Review that an event is the signal that starts the steps.

## Guided Practice (6 minutes)

1. Give a new long algorithm aloud: hop, hop, hop, hop, hop, spin. The student finds the repeated action and rewrites it with a loop.
2. Try one with two actions repeating: jump, clap, jump, clap, jump, clap, sit.
3. Together, write new instructions that start with an event and contain a loop.
4. Test it. Ring the bell and act it out.

## Independent Practice / Quick Check (5 minutes)

The student writes their own instructions with one event and one loop, using cards or paper, and you carry them out. Then show a new repeated sequence and ask the student to shorten it with a loop.

Look for:
- The student identifies the exact section that repeats.
- The loop version produces the same result as the long version.
- The student's own instructions include both an event and repetition.

## Differentiation

**For students needing support**
- Use a single repeated action before trying a repeated pair.
- Color the repeated cards so the pattern is visible.

**For students ready for more**
- Put two different loops in one algorithm.
- Find the loop in a song with a repeated chorus and write it as REPEAT.

## Extensions

- Write a dance with loops and teach it to someone.
- Look for loops in a recipe or a knitting or craft pattern.

## Notes for Parent/Instructor

- The key check is that the loop version behaves the same as the original. Always act out both.
- Keep the REPEAT and WHEN cards. They match blocks the student will see in Lessons 5 and 6.
