**Standards covered (2024 Virginia Computer Science SOL)**

- **2.AP.1** The student will apply computational thinking to identify patterns, and design algorithms to compare and contrast objects based on attributes.
  - a. Compare and contrast multiple ways to sort a set of objects.
  - b. Create a table of features to organize objects.

## Prep

- Choose a set where each object can be described by at least three features, such as color, size, and number of wheels.
- Draw a blank table with object names down the side and three feature headings across the top.

## Warm-up (3 minutes)

Spread out the objects. Ask the student to sort them any way they like, then to sort the same objects a different way. Ask, "Which sort was easier? Did the groups change?"

## Direct Instruction (5 minutes)

- Explain: "The same set can be sorted in many ways. Comparing the ways tells us which sort is most useful for a job."
- Sort by one feature, then by another. Say what is alike about the two sorts (same objects) and what is different (number and size of groups).
- Introduce the table of features: each row is one object, and each column is one feature.
- Fill in two rows aloud: "Fire truck: red, large, six wheels."
- Show how the table helps: run a finger down one column to find every object that shares a feature.

## Guided Practice (6 minutes)

1. Fill in the rest of the table together. The student says each feature before writing or drawing it.
2. Use the table to answer: "Which objects are red? Which are red and small?"
3. Sort the real objects by one column, then by a different column.
4. Ask, "How are these two sorts alike? How are they different?"

## Independent Practice / Quick Check (4 minutes)

The student chooses a third way to sort, does it, and tells you how it compares with the first two. Then the student uses the table to find all the objects that match a feature you name.

Look for:
- The student sorts the same set in more than one way and compares the sorts.
- The table has one row per object and one column per feature.
- The student reads the table to find objects with a given feature.

## Differentiation

**For students needing support**
- Use six objects and two features.
- Fill in the table with drawings or color marks in place of words.

**For students ready for more**
- Add a fourth feature column that needs counting or measuring.
- Ask which sort would be most useful to a toy store and why.

## Extensions

- Make a table of features for the family's pets, shoes, or favorite foods.
- Sort a set of books two ways and decide which way belongs on the shelf.

## Notes for Parent/Instructor

- Grade 1 sorted by two attributes. Grade 2 adds comparing different sorts and recording features in a table.
- "Table of features" is the standard's phrase. It prepares students for organizing data later.
