**Standards covered (2024 Virginia Computer Science SOL)**

- **1.DA.2** The student will create representations of data to make predictions and draw conclusions.
  - a. Collect and organize data with or without a computing device.
  - b. Create tables, object graphs, picture graphs, and models using abstraction.

## Prep

- Choose a question the student can investigate today, such as what kinds of shoes are by the door, what colors the toy cars are, or which fruit each family member likes best.
- Draw the blank table and the blank picture graph grid.

## Warm-up (3 minutes)

Pose the question. Ask the student to guess the answer. Then ask, "How could we find out for sure, and how could we show someone else what we found?"

## Direct Instruction (6 minutes)

- Name the steps: "First we collect data. Then we organize it. Then we show it."
- Model collecting: look at or ask about each item one at a time and make one tally mark in the table for each.
- Model organizing: count the tallies in each row and write the total. "A table puts data in rows so it is easy to read."
- Model showing: on the grid, draw one simple circle or place one sticker for each item, one column per choice.
- Explain abstraction: "I did not draw every lace and buckle on each shoe. I used one plain circle to stand for one shoe. Leaving out the details we do not need is called abstraction. It makes the graph quick to make and easy to read."
- Mention the choices: "We could also line up the real objects. That is an object graph. A drawing or model that stands for something real is another way to show data."

## Guided Practice (6 minutes)

1. Collect the rest of the data together. The student makes the tally marks.
2. The student counts each row and writes the totals.
3. Start the picture graph together. Ask, "What will one sticker stand for?"
4. Add a title and a label under each column.

## Independent Practice / Quick Check (5 minutes)

The student finishes the picture graph alone and checks that each column matches the total in the table. Ask, "Why did we use a sticker and not a detailed drawing?"

Look for:
- One tally mark for each item, with correct totals.
- The graph matches the table.
- The student explains that the simple picture stands for the real thing.

## Differentiation

**For students needing support**
- Use three choices and no more than ten items.
- Build an object graph with the real items first, then swap each object for a sticker.
- Make the tally marks together.

**For students ready for more**
- Collect the data by asking people a survey question.
- Let one picture stand for two items and discuss how that changes the graph.

## Extensions

- If a device is available, take a photo of the table and graph to store them.
- Repeat with a new question each week and keep the graphs in a folder.

## Notes for Parent/Instructor

- "Using abstraction" in the standard means letting a simple mark or picture stand for something real, keeping only what matters for the question.
- The standard allows data collection "with or without a computing device." This lesson is written without one.
- Keep the finished table and graph. They are used in Lesson 15.
