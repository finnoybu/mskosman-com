**Standards covered (2024 Virginia Computer Science SOL)**

- **3.AP.2** The student will plan and implement algorithms that consist of events and conditional control structures using a block-based programming language.
  - a. Describe the concept of a conditional control structure.

## Prep

- Write IF, THEN, and ELSE on separate cards.

## Warm-up (3 minutes)

Play a round of "red light, green light." Then ask, "How did you decide whether to move?"

## Direct Instruction (5 minutes)

- Define: "A conditional is an instruction that checks whether something is true and then chooses what to do."
- Explain the term: "It is called a conditional control structure because a condition controls which steps run."
- Lay out the cards: IF the square is green, THEN take a step. ELSE stand still.
- Name the parts: the condition (a question with a true or false answer), the action when it is true, and the action when it is false.
- Contrast with a loop: a loop repeats steps, and a conditional chooses between steps.

## Guided Practice (6 minutes)

1. Hold up colored squares one at a time. The student follows the conditional.
2. The student writes a new conditional on cards for you to follow.
3. Find conditionals in daily life: IF it is raining, THEN wear boots, ELSE wear sneakers.
4. Ask for each, "What is the condition? What happens when it is true? When it is false?"

## Independent Practice / Quick Check (4 minutes)

The student explains what a conditional is to you as if you had never heard of it, then writes two conditionals with IF, THEN, and ELSE and identifies the condition in each.

Look for:
- The student describes a conditional as a check that chooses an action.
- Each condition can be answered true or false.
- Both the true and false actions are stated.

## Differentiation

**For students needing support**
- Start with IF and THEN only and add ELSE later.
- Use physical actions for every example.

**For students ready for more**
- Put a conditional inside a loop: REPEAT 5 TIMES: IF... THEN... ELSE...
- Write a conditional with two conditions joined by AND.

## Extensions

- Make a board game rule sheet using IF, THEN, ELSE.
- Spot conditionals in household rules for a day.

## Notes for Parent/Instructor

- Grade 1 used "if" informally. Grade 3 names the structure and its parts.
- A good condition has only two possible answers. Check each of the student's conditions for that.
