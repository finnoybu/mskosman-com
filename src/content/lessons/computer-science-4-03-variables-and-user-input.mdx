**Standards covered (2024 Virginia Computer Science SOL)**

- **4.AP.2** The student will plan and implement algorithms that consist of sequencing, loops, variables, user input, and conditional control structures using a block-based programming language.
  - a. Identify user input and its role in improving a program.
  - b. Describe the concept of a variable.

## Prep

- Label the boxes with sticky notes: score, playerName, lives.

## Warm-up (3 minutes)

Ask, "When you play a game, how does it remember your score? How does it know your name?"

## Direct Instruction (5 minutes)

- Define variable: "A named place where a program stores a value that can change." The box is the variable, the label is its name, and the slip inside is its value.
- Demonstrate: put 0 in score. Take it out and replace it with 10. The name stays the same while the value changes.
- Explain good names: a name should say what is stored.
- Define user input: "Information a person gives to a program while it runs," such as typing a name, clicking, or pressing a key.
- Explain the benefit: input lets one program respond to different people and choices, so it is more useful and personal.

## Guided Practice (6 minutes)

1. Play a round: you call out events ("collect a coin, plus 5") and the student updates the slip in score.
2. Ask the student's name and store it in playerName. Read a greeting that uses it.
3. Ask, "What would the program be like if it could not ask for your name?"
4. The student invents a fourth variable for a game and names it.

## Independent Practice / Quick Check (4 minutes)

The student explains what a variable is using the box, gives two examples of user input, and tells how input would improve a quiz program.

Look for:
- A variable is described as named storage whose value can change.
- Examples of user input are things a person provides.
- The improvement described is specific.

## Differentiation

**For students needing support**
- Use one box for the whole lesson.
- Keep to numbers before storing words.

**For students ready for more**
- Use two variables together: score increases by the value in bonus.
- Decide what a variable should hold at the very start of a game and why.

## Extensions

- Keep score of a board game using labeled boxes.
- Spot variables in a favorite game: health, coins, level.

## Notes for Parent/Instructor

- The box model works well, but note one limit: a variable holds one value at a time.
- Both ideas are used in programs starting in Lesson 5.
