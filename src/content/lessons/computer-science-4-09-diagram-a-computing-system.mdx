**Standards covered (2024 Virginia Computer Science SOL)**

- **4.CSY.1** The student will model how a computing system works to accomplish a task.
  - d. Diagram and describe a simple computing system indicating processors, inputs, and outputs.

## Warm-up (2 minutes)

Name a smart speaker or a game console. Ask, "What goes in? What comes out? What happens in between?"

## Direct Instruction (4 minutes)

- Review the three parts: inputs bring data in, the processor follows the program, and outputs deliver the result.
- Set diagram rules: a labeled box for each part, arrows showing the direction data moves, and a title.
- Model a diagram for a game console: controller buttons into the processor, then out to the screen and speaker.
- Narrate one task along the arrows: pressing jump.

## Guided Practice (6 minutes)

1. The student chooses a system and lists its inputs and outputs.
2. The student draws the diagram with labels and arrows.
3. Add any sensors as inputs.
4. The student describes one task by tracing the arrows.

## Independent Practice / Quick Check (4 minutes)

The student diagrams a second, different system on their own and describes how it accomplishes one task.

Look for:
- Inputs, processor, and outputs are all shown and labeled.
- Arrows point in the direction data travels.
- The description follows the diagram.

## Differentiation

**For students needing support**
- Provide the three boxes and have the student add labels and arrows.
- Diagram a calculator.

**For students ready for more**
- Add storage and a network connection to the diagram.
- Diagram a system with several inputs and outputs and color-code them.

## Extensions

- Diagram a household appliance that contains a computer.
- Compare your diagram with someone else's diagram of the same device.

## Notes for Parent/Instructor

- Grade 3 built a physical model. Grade 4 asks for a labeled diagram.
- A short lesson. Use spare time to trace more tasks through the diagram.
