**Standards covered (2024 Virginia Computer Science SOL)**

- **6.CSY.1** The student will define and explain application software and operating systems of a computing device within a computing system.
  - a. Define and describe the functions of an operating system and application software.
  - b. List advantages and limitations of application software and operating systems based on the needs of the user.

## Prep

- List the operating systems on your family's devices and six applications you use.
- Make a card for each.

## Warm-up (3 minutes)

Ask, "When you turn on a tablet, something is already running before you open any app. What is it doing?"

## Direct Instruction (5 minutes)

- Define operating system: the software that manages a device's hardware and resources, runs other programs, manages files, and provides the interface. Give examples from your devices.
- Define application software: programs that help a user do a particular task, such as writing, browsing, drawing, or playing.
- Describe the relationship: applications ask the operating system for what they need, and it manages the hardware for them.
- Discuss advantages and limitations by user need: an application may run on only some operating systems; some need a fast processor or lots of storage; some cost money; some are simple and others are powerful but complex.

## Guided Practice (6 minutes)

1. The student sorts the cards into operating systems and applications.
2. For two applications, list which operating systems they run on and what they are best for.
3. Pose user profiles: a photographer, a grandparent who video calls, a student writing reports. Which fits each?
4. Chart one advantage and one limitation for each choice.

## Independent Practice / Quick Check (4 minutes)

The student defines both terms, describes two functions of an operating system, and recommends software for a user you describe, giving an advantage and a limitation.

Look for:
- The two kinds of software are distinguished correctly.
- Operating system functions are accurate.
- The recommendation is tied to the user's needs.

## Differentiation

**For students needing support**
- Use the comparison of a building manager and the tenants.
- Sort four cards.

**For students ready for more**
- Compare two operating systems on features that matter to a specific user.
- Find out what happens when an operating system is no longer updated.

## Extensions

- Find the operating system version on each family device.
- Compare two apps that do the same job.

## Notes for Parent/Instructor

- Students often think the operating system is the device. Separate hardware from the software that manages it.
- User needs are the standard's lens. Always ask, "Best for whom?"
