**Standards covered (2024 Virginia Computer Science SOL)**

- **K.DA.2** The student will create representations of data to make predictions and draw conclusions.
  - a. Create tables, object graphs, picture graphs, and/or models.
  - b. Describe the information from a given data visualization.
  - c. Use data to answer questions, make predictions, and draw conclusions.

## Prep

- Draw a grid with 3 or 4 columns and label the bottom of each column.
- Make one finished picture graph on a different topic, such as family members' favorite fruits, with two to five pictures in each column.
- Set aside a small new set of items in three kinds for the independent practice.

## Warm-up (3 minutes)

Show the recording sheet from last time. Ask, "What did we find out?" Then ask, "Could we show this so someone could understand it just by looking?"

## Direct Instruction (6 minutes)

- Explain: "A graph is a picture of data. It helps us see the answer quickly."
- Build an **object graph**: line up the real items in columns on the table, one column per color, starting from the same bottom line. "This graph is made of the real objects."
- Build a **picture graph**: on the grid, draw or stick one picture for each item, one box each, starting from the bottom. "This graph uses pictures in place of the objects."
- Read the graph aloud: "Red has five. Blue has three. Red has the most."
- Model three kinds of thinking:
  - Answer a question: "Which color has the fewest?"
  - Make a prediction: "If I grab one more block without looking, which color do I think it will be? Why?"
  - Draw a conclusion: "So, our pile is mostly red."

## Guided Practice (5 minutes)

1. Show your prepared picture graph on a new topic (for example, favorite fruits of family members).
2. Ask, "What is this graph about? What does each picture stand for?"
3. Ask the student to tell you two things the graph shows.
4. Ask one "most or fewest" question, one prediction question, and one "So what do we know?" question.

## Independent Practice / Quick Check (6 minutes)

Give the student a small new set of items in three kinds. The student builds an object graph, then tells you what it shows. Ask one question, ask for one prediction, and ask, "What can we say for sure from this graph?"

Look for:
- Items lined up from a common starting line, one per space.
- The student describes the graph (most, fewest, same) without counting everything again.
- The student gives an answer, a prediction, and a conclusion that fit the data.

## Differentiation

**For students needing support**
- Stay with object graphs and two columns.
- Use a muffin tin or ice cube tray to keep items one to a space.
- Ask only "Which has more?"

**For students ready for more**
- The student also makes the picture graph on paper and adds a title.
- Record the same data in a simple table with a number for each row, and compare it to the graph.

## Extensions

- Graph the shoes by the door by type, or the fruit in the bowl.
- Ask a family question (favorite season), collect answers, and make a picture graph to share at dinner.

## Notes for Parent/Instructor

- The standard lists tables, object graphs, picture graphs, and models joined by "and/or." This lesson teaches object and picture graphs, with a table as a stretch option.
- Lining items up from the same starting line matters. Uneven spacing makes a shorter column look longer.
- Accept any prediction the student can explain from the graph. The reasoning is what counts.
