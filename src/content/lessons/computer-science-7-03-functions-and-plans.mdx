**Standards covered (2024 Virginia Computer Science SOL)**

- **7.AP.2** The student will plan and implement algorithms that include sequencing, loops, variables, user input, conditional control structures, and functions using a block-based or text-based programming tool.
  - a. Describe the concept of functions for use in a computer program.
  - b. Plan an algorithm using plain language, pseudocode, or diagrams.

## Warm-up (3 minutes)

Ask, "When a recipe says 'make the frosting, see page 40,' why does it not repeat all the frosting steps there?"

## Direct Instruction (5 minutes)

- Define function: "A named block of code that performs one task and can be run, or called, whenever needed." Some tools call it a procedure or a custom block.
- Explain inputs and outputs: a function can take parameters, which are values given to it, and may return a result.
- Give the reasons: write once and reuse, shorter and clearer programs, easier testing and fixing, and the ability to think at a higher level.
- Model a plan in pseudocode: DEFINE drawStar(x, y, size). Then the main algorithm: REPEAT 50 TIMES: CALL drawStar with random values.

## Guided Practice (7 minutes)

1. The student identifies one repeated procedure from the brief and names it as a function.
2. Decide its parameters.
3. Write the function's steps in pseudocode on a card.
4. Write the main algorithm that calls it, or draw it as a flowchart.

## Independent Practice / Quick Check (4 minutes)

The student completes the plan: at least one function with parameters, and a main algorithm using sequencing, a loop, a conditional, and a call to the function.

Look for:
- A function is described as a named, reusable block.
- Parameters are sensible.
- The plan could be followed by another person.

## Differentiation

**For students needing support**
- Write a function with no parameters first.
- Use the recipe comparison throughout.

**For students ready for more**
- Plan a function that returns a value.
- Plan one function that calls another.

## Extensions

- Find functions in a program you have used or read.
- Rewrite an older project's plan using functions.

## Notes for Parent/Instructor

- Functions are the main new idea in Grade 7 programming.
- The words function, procedure, and custom block vary by tool. The idea is the same.
