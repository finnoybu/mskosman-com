**Standards covered (2024 Virginia Computer Science SOL)**

- **4.AP.2** The student will plan and implement algorithms that consist of sequencing, loops, variables, user input, and conditional control structures using a block-based programming language.
  - e. Write programs that initialize, assign values to, name, and modify variables.
- **4.AP.3** The student will use the iterative design process to create, test, and debug programs containing sequencing, loops, variables, user inputs, and conditional control structures in a block-based programming tool.
  - b. Create and use variables to store and process data.

## Prep

- Find where the tool creates variables and locate the blocks that set a variable and change a variable.
- Build a tiny sample that counts clicks on a character.

## Warm-up (2 minutes)

Run your click-counter sample. Ask, "What is the program remembering? Where do you think it keeps it?"

## Direct Instruction (5 minutes)

- Teach the four actions with their terms: name the variable when you create it; initialize it by setting its first value at the start; assign a value with a set block; modify it with a change block.
- Explain why initializing matters: without it, the variable keeps its value from the last run.
- Show how to display the variable on screen.
- Show processing: use the variable in a calculation or a say block, such as saying the score.

## Guided Practice (8 minutes)

1. The student creates a variable with a clear name.
2. The student initializes it to 0 when the program starts.
3. The student adds an event that changes it by 1 and tests it.
4. The student makes the character say the value.

## Independent Practice / Quick Check (5 minutes)

The student adds a second variable, such as one that counts down, initializes it, modifies it, and uses both variables in the program's output.

Look for:
- Variables have meaningful names.
- Each variable is initialized at the start.
- Values are modified and then used by the program.

## Differentiation

**For students needing support**
- Work with one variable only.
- Keep the box model beside the screen and update it as the program runs.

**For students ready for more**
- Use one variable to change another.
- Store a word in a variable and join it into a sentence.

## Extensions

- Add a score to an earlier project.
- Make a counter program for a real use, such as counting laps or pages read.

## Notes for Parent/Instructor

- Forgetting to initialize is the most common early error. Run the program twice to reveal it.
- This lesson covers both writing variables and using them to store and process data.
