**Standards covered (2024 Virginia Computer Science SOL)**

- **1.AP.1** The student will apply computational thinking by sorting items into categories based on multiple attributes and create patterns.
  - d. Create repeating and increasing patterns.

## Warm-up (3 minutes)

Clap a simple rhythm: clap, clap, stomp, clap, clap, stomp. Ask the student to join in, then ask, "How did you know what came next?"

## Direct Instruction (5 minutes)

- Explain: "A pattern follows a rule. If you know the rule, you know what comes next."
- Build a **repeating pattern** with blocks: red, red, blue, red, red, blue. Circle the part that repeats with your finger. "This part repeats again and again."
- Build an **increasing pattern**: one block, then two blocks, then three blocks, in separate stacks. "This pattern grows. Each step has one more than the step before."
- Compare them: "A repeating pattern stays the same size each time. An increasing pattern gets bigger each time."
- Say the rule for each out loud.

## Guided Practice (6 minutes)

1. Together, build a new repeating pattern with three parts. The student says the repeating part.
2. Extend it two more times.
3. Together, build an increasing pattern that adds two each time. Ask, "How many will the next step have? How do you know?"
4. Show a pattern and ask, "Is this repeating or increasing?"

## Independent Practice / Quick Check (5 minutes)

The student creates one repeating pattern and one increasing pattern with the items, then draws both on paper. Ask the student to tell you the rule for each.

Look for:
- The repeating pattern repeats correctly at least three times.
- The increasing pattern grows by the same amount each step.
- The student can state each rule.

## Differentiation

**For students needing support**
- Stay with two-part repeating patterns until they are secure.
- Build increasing patterns as staircases so the growth is easy to see.
- Copy your pattern first, then change one color to make it their own.

**For students ready for more**
- Make a repeating pattern that uses two attributes, such as color and position.
- Make an increasing pattern, hide one step, and have a partner find what is missing.

## Extensions

- Create sound or movement patterns and teach them to someone else.
- Look for increasing patterns in the real world: stairs, stacking cups, a growing line of dominoes.

## Notes for Parent/Instructor

- The standard asks students to create patterns, not only continue them. Make sure the student invents at least one of each kind.
- "Increasing" is the standard's word. "Growing" is a helpful everyday partner for it.
- If an increasing pattern grows unevenly, ask, "How many more did you add each time?"
