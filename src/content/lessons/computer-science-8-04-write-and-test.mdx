**Standards covered (2024 Virginia Computer Science SOL)**

- **8.AP.2** The student will plan and implement algorithms that include sequencing, loops, variables, user input, conditional control structures, functions, and various data types.
  - c. Write and test algorithms expressed using block-based or text-based programming languages.
- **8.AP.3** The student will use the iterative design process to create, test, and debug programs using a block-based or text-based programming language.
  - a. Create and test programs that contain multiple control structures.

## Prep

- Make sure the programming tool is ready and the student's plan is at hand.

## Warm-up (2 minutes)

Ask, "Looking at your plan, what is the smallest piece you could build and test in ten minutes?"

## Direct Instruction (3 minutes)

- Set the working method: build one function at a time, test it, then connect it.
- Review writing a test before the code: decide the inputs and expected results first.
- Encourage comments that explain the purpose of each function.
- Remind the student to save versions as they go.

## Guided Practice (10 minutes)

1. The student writes the input handling with checks and tests it with valid and invalid data.
2. Write the first function and test it alone.
3. Write the main loop and conditional that use it.
4. Run the essential version end to end.

## Independent Practice / Quick Check (5 minutes)

The student continues to a working essential version, then lists the tests run so far and their results.

Look for:
- The program follows the plan.
- Multiple control structures, functions, and data types are used.
- Each part is tested as it is built.

## Differentiation

**For students needing support**
- Build a reduced version with one function.
- Pair on the first function.

**For students ready for more**
- Add a list and process it with a loop.
- Add a second function that calls the first.

## Extensions

- Continue building over several sessions.
- Keep a development journal.

## Notes for Parent/Instructor

- This lesson is mostly hands-on time. It may take more than one session.
- Insist on a test for each function before moving on.
