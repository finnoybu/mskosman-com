**Standards covered (2024 Virginia Computer Science SOL)**

- **3.CSY.1** The student will model how computing devices within a computing system work.
  - d. Model how a computing system works including input and output, processors, and sensors.

## Prep

- Pick a familiar system to model, such as an automatic door, a night-light that turns on in the dark, or a thermostat.

## Warm-up (3 minutes)

Show the night-light or rotate the phone so the screen turns. Ask, "How did it know?"

## Direct Instruction (5 minutes)

- Define sensor: "A sensor is an input part that detects something in the world, such as light, motion, temperature, sound, or touch, and sends it as data."
- Describe the automatic door as a system: the motion sensor is the input, the processor checks IF motion is detected, and the motor that opens the door is the output.
- Explain what a model is: a simpler version of something real that shows how it works.
- Sketch the model: boxes for each part, arrows or string showing where data travels, and a label on each.

## Guided Practice (8 minutes)

1. The student chooses a system to model.
2. Together, list its sensor or other input, what the processor decides, and its output.
3. The student builds the model on paper or with the box, using string for the path of data.
4. The student walks a finger along the path, narrating what happens at each part.

## Independent Practice / Quick Check (4 minutes)

The student presents the finished model to you, explaining each part and what happens from the moment the sensor detects something until the output occurs.

Look for:
- The model includes a sensor or other input, a processor, and an output.
- The path of data is shown in the correct order.
- The student explains the processor's decision.

## Differentiation

**For students needing support**
- Model the night-light, which has one sensor and one output.
- Provide the labels ready-made.

**For students ready for more**
- Model a system with two sensors.
- Write the processor's decision as pseudocode with IF, THEN, ELSE.

## Extensions

- Act out the system with family members as sensor, processor, and output.
- Hunt for sensors at home and in stores.

## Notes for Parent/Instructor

- The standard's verb is "model," so the student should make something and explain it.
- This lesson connects computing systems to the conditionals from Lesson 3.
