**Standards covered (2024 Virginia Computer Science SOL)**

- **7.AP.2** The student will plan and implement algorithms that include sequencing, loops, variables, user input, conditional control structures, and functions using a block-based or text-based programming tool.
  - c. Read and write programs that collect and use numeric and text data from users.

## Prep

- Write a sample that asks for a name and an age and prints a sentence using both, with a calculation on the age.
- Check how your tool converts text input to a number and joins text together.

## Warm-up (2 minutes)

Run the sample. Ask, "Which input did the program treat as a number and which as text? How can you tell?"

## Direct Instruction (4 minutes)

- Distinguish numeric data, used in calculations, from text data, called strings, used for names, words, and messages.
- Read the sample together line by line.
- Show the two key operations: converting input to a number before calculating, and joining strings to build output.
- Point out a common error: adding a number stored as text joins the digits instead of adding.

## Guided Practice (8 minutes)

1. The student explains what each line of the sample does.
2. The student writes a program that asks for a word and a number.
3. Use the number in a calculation and the word in the output.
4. Test with different inputs, including unexpected ones.

## Independent Practice / Quick Check (4 minutes)

The student writes a program for a small purpose, such as a personalized greeting with a calculated value, that collects at least one text and one numeric input.

Look for:
- Text and numeric input are both collected.
- Numeric input is used in a calculation.
- Output combines text and a result.

## Differentiation

**For students needing support**
- Modify the sample.
- Collect one input of each type.

**For students ready for more**
- Check input and ask again when it is not valid.
- Use the length of a text input in a calculation.

## Extensions

- Write a program that builds a silly story from user inputs.
- Read a tutorial example and identify its inputs and types.

## Notes for Parent/Instructor

- The error of joining digits is common. Let the student meet it and work out why.
- Reading programs is half the standard. Have the student explain code as well as write it.
