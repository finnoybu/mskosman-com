**Standards covered (2024 Virginia Computer Science SOL)**

- **3.CSY.1** The student will model how computing devices within a computing system work.
  - a. Describe the role of a processor in a computing system.
  - b. Explain the relationship between the inputs, processors, and outputs.
  - c. Discuss various types of input data a computer can accept and use.

## Prep

- Write simple instruction cards for the processor role, such as "add the two numbers" and "make the word all capital letters."

## Warm-up (3 minutes)

Hand the student a calculator. Ask them to press 6, plus, 3, equals. Ask, "Which part of this did the work of adding?"

## Direct Instruction (5 minutes)

- Define: "The processor is the part of a computing system that follows the program's instructions and does the calculating and deciding." It is a small chip inside the device.
- Explain the relationship: input brings data in, the processor works on it according to the program, and output shows the result.
- Trace the calculator example through all three.
- Discuss types of input data: text and numbers from a keyboard, clicks and touches, sound from a microphone, images from a camera, and readings from sensors such as temperature or motion.

## Guided Practice (6 minutes)

1. Role-play: one person gives input on a card, the student as processor follows an instruction card, and writes the output.
2. Swap the instruction card and repeat with the same input. Ask, "Why did the output change?"
3. For three devices, the student names one type of input data each accepts.
4. Ask, "What would happen with no processor? With no input?"

## Independent Practice / Quick Check (4 minutes)

The student draws a diagram with three boxes and arrows, labels input, processor, and output, and explains it using a real example. Then the student lists four types of input data.

Look for:
- The student describes the processor as following instructions and doing the work.
- The diagram shows data moving from input through the processor to output.
- Several different types of input data are named.

## Differentiation

**For students needing support**
- Keep the three signs visible and walk between them.
- Use one device and one example throughout.

**For students ready for more**
- Add storage to the diagram and explain when it is used.
- Compare how fast a person and a processor follow the same instruction cards.

## Extensions

- Play the processor game with family members using sillier instruction cards.
- Look up a picture of a processor chip together.

## Notes for Parent/Instructor

- Grade 2 covered input and output. The processor is what sits between them.
- Students often call the whole computer case the processor. Clarify that it is one chip inside.
