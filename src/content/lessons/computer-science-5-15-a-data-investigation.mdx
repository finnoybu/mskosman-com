**Standards covered (2024 Virginia Computer Science SOL)**

- **5.DA.2** The student will create multiple data representations to make predictions and conclusions.
  - a. Formulate questions that require the collection or acquisition of data.
  - b. Collect data to use in creating charts, graphs, and models.
  - c. Analyze data as evidence to draw conclusions and make predictions.
  - d. Propose solutions to problems or questions based on data analysis.

## Prep

- Help the student pick a question tied to a decision, such as when the family uses the most electricity, which chores take longest, or how reading time changes over a week.
- If the data takes days to gather, begin collecting before this lesson.

## Warm-up (2 minutes)

Ask, "What is something at home we could improve if we understood it better?"

## Direct Instruction (4 minutes)

- Review the steps: question, collect, represent, analyze, propose.
- Explain multiple representations: the same data shown as a table, a bar graph, a line graph, or a model. Each shows something different.
- Define evidence: data that supports a claim. A conclusion should point to it.
- Explain proposing a solution: say what should change and which data supports it.

## Guided Practice (9 minutes)

1. The student writes the question.
2. Enter the collected data in the spreadsheet.
3. Create two different representations.
4. Discuss what each one shows best.

## Independent Practice / Quick Check (5 minutes)

The student writes a short report: the question, one conclusion with evidence, one prediction, and a proposed solution based on the analysis.

Look for:
- The question requires data.
- Two representations are created and labeled.
- Claims point to specific data.

## Differentiation

**For students needing support**
- Use a prepared data set.
- Provide the report headings.

**For students ready for more**
- Add a third representation or a simple model.
- Collect more data after trying the solution and see whether it worked.

## Extensions

- Present the report to the family.
- Repeat the cycle with a new question.

## Notes for Parent/Instructor

- This lesson may run over more than one session if data collection is slow.
- Ask "What is your evidence?" for every claim.
