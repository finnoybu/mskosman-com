**Standards covered (2024 Virginia Computer Science SOL)**

- **K.AP.1** The student will apply computational thinking to identify patterns and sort items into categories based on an attribute.
  - a. Identify attributes of a set of objects.
  - c. Sort and classify concrete objects based on one attribute.

## Warm-up (3 minutes)

Hold up two of the objects. Ask, "What do you notice about these?" Accept every describing word the student offers: red, big, round, soft, bumpy. Repeat each word back.

Tell the student, "Those describing words have a special name. Each one is an attribute."

## Direct Instruction (4 minutes)

- Define the word: an **attribute** is something you can notice about an object, such as its color, its size, or its shape.
- Pick up one object and name three of its attributes out loud: "This button is blue. It is small. It is round."
- Introduce sorting: "Sorting means putting things that are alike together."
- Model a sort by color with six objects. Think aloud as you place each one: "This one is red, so it goes with the reds."
- Point to one finished group and say, "Everything in this group shares the same attribute."

## Guided Practice (5 minutes)

1. Sort the remaining objects by color together. The student names the color before placing each object.
2. Mix all the objects back together.
3. Sort again, this time by size (big and small). Ask, "What attribute are we using now?"
4. Hold up one object and ask where it belongs and why.

## Independent Practice / Quick Check (4 minutes)

Mix the objects one more time. Say, "Choose one attribute and sort everything your way. Do not tell me your rule yet."

When the student finishes, ask, "What attribute did you sort by?"

Look for:
- The student names at least two attributes of a single object.
- Every object is placed using the same one attribute.
- The student can say the attribute that was used.

## Differentiation

**For students needing support**
- Use only six objects and two colors.
- Give the attribute yourself ("Sort by color") before asking the student to choose one.
- Have the student touch and say the attribute for each object before placing it.

**For students ready for more**
- Sort by an attribute you have not modeled, such as texture or what the object is made of.
- You sort the objects silently, and the student guesses the attribute you used.

## Extensions

- Sort the laundry, the silverware drawer, or a shelf of books by one attribute.
- Go on an attribute hunt: find three things in the room that are round.

## Notes for Parent/Instructor

- Choose objects that can be sorted more than one way. A set that is all one color only teaches one sort.
- If the student mixes two attributes (some by color, some by size), ask, "What is the same about everything in this group?" and let them fix it.
- The word "attribute" is new and long. Use it often and expect the student to need several lessons before using it unprompted.
- The next lesson compares two objects and looks for patterns.
