**Standards covered (2024 Virginia Computer Science SOL)**

- **8.AP.3** The student will use the iterative design process to create, test, and debug programs using a block-based or text-based programming language.
  - b. Trace and predict outcomes of programs.
  - c. Analyze the outcomes of programs to identify logic and syntax errors.

## Prep

- Prepare two short programs: one with a function and a loop that has an off-by-one error, and one with a syntax error and a wrong condition.

## Warm-up (3 minutes)

Ask, "A loop is meant to run ten times and runs nine. How would you find out why without guessing?"

## Direct Instruction (4 minutes)

- Review tracing with functions: track each variable, including values passed to and returned from functions.
- Name common logic errors: off-by-one in loops, reversed comparisons, wrong order of operations, a variable not reset, and the wrong variable used.
- Review syntax errors and reading error messages: the message, the line, and the cause may be just before that line.
- Introduce tools: printing values at key points, and a debugger that steps through code if your tool has one.

## Guided Practice (8 minutes)

1. The student traces the first program and predicts its output.
2. Run it, compare, and locate the off-by-one error.
3. Fix the syntax error in the second using the message.
4. Add print statements to find the wrong condition.

## Independent Practice / Quick Check (5 minutes)

The student traces one function of their own program for an edge case, predicts the outcome, runs it, and reports any error found with its type.

Look for:
- Traces track every relevant variable.
- Errors are classified as logic or syntax.
- Diagnosis uses evidence, not guesswork.

## Differentiation

**For students needing support**
- Trace a program with one loop and no functions.
- Provide a partly filled trace table.

**For students ready for more**
- Use a debugger to step through code.
- Find an error that appears only with certain inputs.

## Extensions

- Debug an open-source beginner program.
- Teach someone the difference between the two kinds of error.

## Notes for Parent/Instructor

- Off-by-one errors are the classic loop mistake. Tracing first and last passes finds them.
- Printing values is simple and remains useful at every level.
