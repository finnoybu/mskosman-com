**Standards covered (2024 Virginia Computer Science SOL)**

- **2.AP.1** The student will apply computational thinking to identify patterns, and design algorithms to compare and contrast objects based on attributes.
  - c. Design an algorithm to sort objects into categories based on multiple attributes.

## Prep

- Label four containers for two attributes with two values each, such as red and large, red and small, not red and large, not red and small.

## Warm-up (3 minutes)

Ask the student to sort five objects while you watch. Then ask, "What did you decide first for each one? What did you decide second?"

## Direct Instruction (5 minutes)

- Review: an algorithm is a set of step-by-step instructions that someone else could follow.
- Explain that a sorting algorithm asks the same questions about every object, in the same order.
- Model writing one on cards: 1. Pick up one object. 2. IF it is red, go to step 3. IF it is not red, go to step 4. 3. IF it is large, put it in the red and large box. IF it is small, put it in the red and small box. 4. Do the same check for size with the not red boxes. 5. REPEAT until no objects are left.
- Follow your cards exactly with two objects to show that they work.

## Guided Practice (6 minutes)

1. The student follows your algorithm with three more objects, reading each card aloud.
2. Together, design a new algorithm for two different attributes. The student decides the questions and their order.
3. Write it on cards and test it with four objects.
4. Fix any step that is unclear or sends an object to the wrong place.

## Independent Practice / Quick Check (5 minutes)

The student designs a sorting algorithm for two attributes of their choice, writes or dictates the steps, and gives it to you to follow exactly with the whole set.

Look for:
- The algorithm checks more than one attribute.
- The steps are in a clear order and include a repeat.
- Every object ends up in the correct category when the steps are followed exactly.

## Differentiation

**For students needing support**
- Provide the card for the first question and let the student write the second.
- Sort into only three containers by making one attribute decide alone.

**For students ready for more**
- Design an algorithm that uses three attributes.
- Design two different algorithms that give the same result and compare them.

## Extensions

- Write a sorting algorithm for putting away groceries or laundry and have a family member follow it.
- Trade algorithms with a sibling or friend and test each other's.

## Notes for Parent/Instructor

- Follow the student's steps literally. Gaps in the algorithm show up quickly when you do.
- This lesson combines sorting from Lesson 1 with the IF and REPEAT ideas from Grade 1.
