**Standards covered (2024 Virginia Computer Science SOL)**

- **1.AP.1** The student will apply computational thinking by sorting items into categories based on multiple attributes and create patterns.
  - a. Describe attributes of a set of objects.
  - b. List the attributes a set of objects have in common.
  - c. Sort and classify concrete objects based on multiple attributes.

## Prep

- Choose objects that differ in at least two clear ways, such as color and size.
- Draw a two-by-two grid on paper. Label the two rows with two colors and the two columns big and small.

## Warm-up (3 minutes)

Hold up one object. Ask, "How many ways can you describe this?" Count the describing words on your fingers. Remind the student that each describing word is an attribute.

## Direct Instruction (5 minutes)

- Describe one object fully: "It is red. It is small. It is a circle. It is smooth."
- Pick up a set of three objects that share something. Say, "Listing what a set has in common means finding the attributes that are true for every object in it." Model: "All of these are blue. All of these are small."
- Introduce sorting with two attributes at once: "This object is red AND big. It has to match both."
- Show the grid. Place three objects, thinking aloud about the row and the column each time.

## Guided Practice (5 minutes)

1. The student picks an object and describes it with at least three attributes.
2. Hand over a set of four objects. Together, list everything they have in common.
3. Sort the remaining objects on the grid together. Before each one is placed, the student says both attributes: "blue and small."
4. Point to one box and ask, "What is true about everything in here?"

## Independent Practice / Quick Check (4 minutes)

Clear the grid. Change one label (for example, replace size with shape). The student sorts ten objects alone, then explains one box.

Look for:
- The student describes an object using several attributes.
- The student names an attribute shared by a whole set.
- Each object is placed using both attributes.

## Differentiation

**For students needing support**
- Sort by one attribute first, then split each group by a second attribute.
- Use only two colors and two sizes.
- Say the first attribute yourself and let the student add the second.

**For students ready for more**
- Add a third attribute and sort into more groups.
- Hide the labels, sort the objects yourself, and have the student work out your two rules.

## Extensions

- Sort a deck of playing cards by color and by number or picture card.
- Sort clean laundry by owner and by type of clothing.

## Notes for Parent/Instructor

- Kindergarten work sorted by one attribute. The step up in Grade 1 is holding two attributes in mind at the same time.
- If the student places an object using only one attribute, ask, "Does it match the row? Does it match the column?"
- "Have in common" is the phrase in the standard. Use it often.
