**Standards covered (2024 Virginia Computer Science SOL)**

- **4.DA.1** The student will identify the appropriate type of data needed to solve a problem or answer a question.
  - c. Use numeric values to represent non-numeric ideas to include binary, American Standard Code for Information Interchange (ASCII), and RGB values.

## Prep

- Print or copy the ASCII values for A to Z.
- If using a device, find a drawing program or web tool with an RGB color picker.

## Warm-up (3 minutes)

Ask, "A computer only stores numbers. So how does it store the letter A, or the color purple?"

## Direct Instruction (6 minutes)

- State the idea: every kind of information is represented by numbers according to an agreed code.
- Binary: the computer's numbers are stored as patterns of 1s and 0s. Review counting with place values 8, 4, 2, 1.
- ASCII: a standard code that gives each character a number. Capital A is 65, B is 66, and so on.
- RGB: a color is three numbers from 0 to 255, for how much red, green, and blue light to mix. (255, 0, 0) is red, (0, 0, 0) is black, and (255, 255, 255) is white.
- Explain why standards matter: every device agrees on the same code, so information can be shared.

## Guided Practice (7 minutes)

1. The student encodes their first name in ASCII numbers.
2. Decode a short word you wrote in ASCII.
3. Write three small numbers in binary.
4. Color three grid squares from RGB values you give, estimating with pencils or using the color picker.

## Independent Practice / Quick Check (4 minutes)

The student encodes a three-letter word in ASCII, writes the number 6 in binary, and gives RGB values for two colors, explaining what each number means.

Look for:
- Letters are converted to the correct ASCII numbers.
- The binary pattern is correct.
- The student explains RGB as amounts of red, green, and blue.

## Differentiation

**For students needing support**
- Do ASCII only, then add RGB another day.
- Use only the three pure RGB colors and black and white.

**For students ready for more**
- Convert an ASCII number into binary.
- Mix custom colors by adjusting one RGB value at a time and describing the change.

## Extensions

- Write a secret message in ASCII for someone to decode.
- Design a pixel picture on grid paper and list its colors as RGB values.

## Notes for Parent/Instructor

- Grade 2 introduced binary. This lesson shows that codes build on it.
- The three codes are named in the standard, so cover all three, even briefly.
