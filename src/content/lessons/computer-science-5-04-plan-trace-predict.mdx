**Standards covered (2024 Virginia Computer Science SOL)**

- **5.AP.2** The student will plan and implement algorithms that consist of sequencing, loops, variables, user input, and nested conditional control structures using a block-based programming language.
  - b. Create a design document to trace and predict an algorithm using plain language, pseudocode, or diagrams.

## Prep

- Draw a trace table with columns: step, input, variable values, output.

## Warm-up (2 minutes)

Ask, "What is cheaper to fix: a mistake in a plan on paper or a mistake in a finished program? Why?"

## Direct Instruction (4 minutes)

- Review what a design document contains: the goal, the inputs, the variables, and the steps as pseudocode or a flowchart.
- Model a plan for a number guessing game: SET secret TO 7. REPEAT UNTIL guess equals secret: ASK for guess. IF guess equals secret THEN SAY correct, ELSE IF guess is less than secret THEN SAY higher, ELSE SAY lower.
- Model tracing it in the table for the guesses 3, 9, 7.
- Predict the output before finishing the trace, then check.

## Guided Practice (8 minutes)

1. The student chooses a program idea that needs a decision inside a decision.
2. The student writes the goal, inputs, and variables.
3. The student writes the steps in pseudocode with indentation.
4. Together, trace it for one set of inputs.

## Independent Practice / Quick Check (5 minutes)

The student traces their own design document for a second set of inputs, records each step in the trace table, and states the predicted outcome.

Look for:
- The plan includes variables, input, a loop, and a nested conditional.
- The trace follows the plan exactly and tracks variable values.
- The prediction comes from the trace.

## Differentiation

**For students needing support**
- Adapt the guessing game plan.
- Trace with the plan and table side by side, covering later lines with paper.

**For students ready for more**
- Trace with an unexpected input and revise the plan to handle it.
- Convert the pseudocode to a flowchart.

## Extensions

- Give the plan to someone else to trace and compare predictions.
- Write a design document for a board game rule.

## Notes for Parent/Instructor

- Keep this design document. Lesson 5 builds from it.
- A plan that cannot be traced is not finished.
