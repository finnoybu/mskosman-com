**Standards covered (2024 Virginia Computer Science SOL)**

- **5.DA.3** The student will explain the significance of training data in machine learning.
  - a. Compare how training data is utilized in supervised, unsupervised and reinforcement learning.
  - b. Explain how training data is used to make classification predictions.
  - c. Discuss the need and significance of diverse, inclusive, and large datasets.

## Prep

- Prepare the cards so the first training set contains only red apples and whole oranges.
- Keep the unusual examples aside.

## Warm-up (3 minutes)

Ask, "If you had only ever seen red apples, what would you say when someone showed you a green one?"

## Direct Instruction (6 minutes)

- Define training data: "The examples a machine learning system learns from."
- Compare the three approaches. Supervised: the training data has labels, and the system learns to match inputs to labels. Unsupervised: no labels, and the system finds groups on its own. Reinforcement: the data comes from the system's own tries, each followed by a reward or penalty.
- Explain classification prediction: after training, the system looks at a new example and predicts which class it belongs to, based on patterns in the training data.
- Explain the need for diverse, inclusive, and large data sets: the system only knows what it has seen. Few or narrow examples lead to wrong or unfair predictions for whatever was left out.

## Guided Practice (7 minutes)

1. Train the student as the model with the first labeled set, using color as the only rule.
2. Test with new cards, then with the unusual examples. Record the mistakes.
3. Add varied examples to the training set and retest.
4. Ask, "What changed? Who or what was the first model unfair to?"

## Independent Practice / Quick Check (4 minutes)

The student explains how training data is used in each of the three approaches, describes how a trained model makes a classification prediction, and gives two reasons data sets should be diverse and large.

Look for:
- The three approaches are distinguished by how data is used.
- Prediction is tied to patterns in training data.
- Reasons mention accuracy and fairness.

## Differentiation

**For students needing support**
- Review the three approaches with the anchors labels, no labels, rewards.
- Run only the supervised activity.

**For students ready for more**
- Design a training set for a new classifier and justify what it includes.
- Discuss a real system that could be unfair if its training data left people out.

## Extensions

- Try a child-friendly tool that trains an image classifier, with an adult.
- Explain training data to a family member using the apple example.

## Notes for Parent/Instructor

- The retraining step is the heart of the lesson. Do not skip it.
- Inclusive means the data represents everyone the system will be used with.
