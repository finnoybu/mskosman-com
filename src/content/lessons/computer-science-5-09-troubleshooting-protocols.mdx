**Standards covered (2024 Virginia Computer Science SOL)**

- **5.CSY.3** The student will evaluate and implement troubleshooting strategies when a computing system is not operational.
  - a. Identify and use troubleshooting protocols to resolve hardware, software, and connectivity issues.
  - b. Apply prior troubleshooting practices to new problems as they arise.

## Prep

- Stage one safe problem the student has not met before, such as sound sent to the wrong output or a file saved in an unexpected place.
- Have any earlier checklist on hand.

## Warm-up (3 minutes)

Ask, "What do pilots and doctors use so they do not skip a step when something goes wrong?"

## Direct Instruction (5 minutes)

- Define protocol: "An agreed set of steps followed in order."
- Write a troubleshooting protocol together: 1. Identify and describe the problem. 2. Decide whether it is hardware, software, or connectivity. 3. Try the simplest fix first. 4. Test. 5. If it is not fixed, try the next strategy. 6. Record what worked. 7. Escalate to an adult with a clear report.
- Explain evaluating strategies: choose by how likely a fix is to work, how quick it is, and how safe it is.
- Explain transfer: a new problem often resembles an old one. Ask, "What does this remind me of?"

## Guided Practice (6 minutes)

1. Present the staged problem. The student follows the protocol aloud.
2. Ask, "Which earlier problem is this like? What worked then?"
3. The student evaluates two possible strategies and picks one.
4. The student records the result in the log.

## Independent Practice / Quick Check (4 minutes)

Describe a problem the student has never met, such as a file that will not open. The student applies the protocol in words, names a similar past problem, and states what they would report if it stayed unsolved.

Look for:
- Protocol steps are followed in order.
- The student connects the new problem to prior experience.
- The report includes what was tried.

## Differentiation

**For students needing support**
- Use a four-step version of the protocol.
- Supply the category of the problem.

**For students ready for more**
- Write a protocol specific to your home network.
- Explain why the simplest fix comes first even when it seems unlikely.

## Extensions

- Add a page to the family troubleshooting guide.
- Help a relative with a real problem using the protocol.

## Notes for Parent/Instructor

- A problem log from earlier years becomes valuable here. Start one now if none exists.
- Escalating with a clear report is a skill, not a failure.
