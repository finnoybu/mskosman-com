**Standards covered (2024 Virginia Computer Science SOL)**

- **6.AP.3** The student will use the iterative design process to create, test, and debug programs using a block-based or text-based programming language.
  - b. Incorporate existing code, media, or libraries into original programs.
- **6.AP.4** The student will demonstrate proper attribution when incorporating ideas and works of others.
  - a. Identify and give proper attribution of information and assets from the Internet and other sources.

## Prep

- Choose one or two existing assets or code elements that are allowed to be reused and note their creator and license.
- Write a credits template: What it is, Creator, Source, License, How I used or changed it.

## Warm-up (3 minutes)

Ask, "Do you think game developers write every line and draw every picture from nothing? Why not?"

## Direct Instruction (4 minutes)

- Explain reuse: programmers build on existing code, media, and libraries. A library is a collection of code written by others that your program can call.
- Give the conditions: you must be allowed to use it, and you must give credit.
- Define attribution: identifying what you used, who created it, where it came from, and its license. It goes in comments in the code and in a credits section.
- Model adding one asset and writing its attribution.

## Guided Practice (8 minutes)

1. The student adds an existing asset or library to a program and uses it.
2. The student writes a comment in the code crediting it.
3. The student fills in the credits template.
4. Ask, "Which part of this program is yours and which is someone else's?"

## Independent Practice / Quick Check (4 minutes)

The student incorporates a second element, attributes it properly, and explains how the original work and the borrowed work fit together.

Look for:
- Existing material is used correctly in the program.
- Attribution includes creator, source, and license.
- The student distinguishes their own work from borrowed work.

## Differentiation

**For students needing support**
- Use one item from the tool's built-in library.
- Fill in the template together.

**For students ready for more**
- Modify a borrowed element and document the change.
- Find out what a specific license requires and check that the program meets it.

## Extensions

- Add a credits screen to an earlier project.
- Review a past report for missing attributions.

## Notes for Parent/Instructor

- Two standards meet here: incorporating existing work and attributing it.
- Attribution does not replace permission. Check that reuse is allowed first.
