**Standards covered (2024 Virginia Computer Science SOL)**

- **5.AP.1** The student will apply computational thinking to identify patterns, make use of decomposition to break down problems or processes into sub-components, and design algorithms.
  - c. Abstract relevant information to identify essential details.
  - d. Design an algorithm to solve a problem.

## Prep

- Write a problem with extra details, such as: "Maya, who has a red bike and a dog named Pepper, needs to visit the library, the bakery, and the park before 4:00, starting from home. Find the shortest order." Include a small sketch map with distances.

## Warm-up (3 minutes)

Show the transit map. Ask, "What does this map leave out about the real city? Why is it still useful?"

## Direct Instruction (5 minutes)

- Define abstraction: "Keeping the details that matter for the problem and leaving out the rest."
- Model with the word problem: cross out what does not affect the answer and circle the essential details, which are the places, the distances, and the goal.
- State the problem in one plain sentence.
- Review designing an algorithm: numbered steps, precise enough to follow, using loops and conditionals where they help, with a clear end.

## Guided Practice (7 minutes)

1. The student restates the essential details of the problem in their own words.
2. Together, design an algorithm that finds the shortest order.
3. Test the algorithm on the sketch map.
4. Change one distance. Ask, "Does the algorithm still work, or only the old answer?"

## Independent Practice / Quick Check (4 minutes)

Give a second detailed problem. The student lists the essential details, ignores the rest, and writes an algorithm to solve it.

Look for:
- Irrelevant details are removed and essential ones kept.
- The algorithm solves the problem in general, not just one case.
- Steps are precise and ordered.

## Differentiation

**For students needing support**
- Highlight details together before the student decides which matter.
- Use a problem with three places.

**For students ready for more**
- Decide which details would matter if the question changed.
- Write an algorithm that works for any number of places.

## Extensions

- Draw an abstract map of your home or neighborhood for a visitor.
- Find the essential information on a crowded poster or web page.

## Notes for Parent/Instructor

- Abstraction, decomposition, pattern recognition, and algorithm design together make up computational thinking.
- An algorithm should solve the type of problem, not one instance. Changing an input tests that.
