**Standards covered (2024 Virginia Computer Science SOL)**

- **3.AP.2** The student will plan and implement algorithms that consist of events and conditional control structures using a block-based programming language.
  - b. Create a design document to plan an algorithm using plain language, pseudocode, or diagrams.

## Prep

- Draw the four flowchart shapes on a reference card: oval for start and end, rectangle for an action, diamond for a condition, arrow for direction.

## Warm-up (3 minutes)

Ask, "If you were building a game where a character collects a star, what would need to happen when the character touches the star? What if it touches a rock?"

## Direct Instruction (5 minutes)

- Review the design document: a plan made before building.
- Show three ways to write it: plain language sentences, pseudocode (short lines such as WHEN, IF, THEN, ELSE, REPEAT), or a diagram.
- Model the same plan two ways. Pseudocode: WHEN the game starts. Move forward. IF touching the star, THEN say "You win." ELSE keep moving.
- Then draw it as a flowchart: oval, rectangle, diamond with a yes arrow and a no arrow.
- Point out that the diamond is the conditional and it always has two ways out.

## Guided Practice (7 minutes)

1. Choose a program idea together.
2. The student writes each step on a sticky note and arranges them.
3. Decide which step is the condition and draw a diamond around it with two arrows.
4. Read the diagram aloud, following both paths.

## Independent Practice / Quick Check (4 minutes)

The student creates a design document for their own program idea that includes an event and a conditional, choosing pseudocode or a flowchart. Keep it for Lesson 5.

Look for:
- The plan starts with an event.
- The conditional has a clear condition and two outcomes.
- Another person could follow the plan.

## Differentiation

**For students needing support**
- Provide a partly drawn flowchart to complete.
- Let the student plan in plain sentences first, then convert one sentence to a diamond.

**For students ready for more**
- Include a loop as well as a conditional.
- Write the same plan in both pseudocode and a flowchart and compare which is clearer.

## Extensions

- Draw a flowchart for a morning decision, such as what to wear.
- Make a flowchart for a simple card game.

## Notes for Parent/Instructor

- The standard allows plain language, pseudocode, or diagrams. Let the student use the form that suits them, after seeing all three.
- Check that every diamond has exactly two exits.
