**Standards covered (2024 Virginia Computer Science SOL)**

- **4.DA.3** The student will create a computational model that represents attributes and behaviors associated with a concept.
  - a. Examine models of physical objects and processes.
  - b. Create a computational model that reflects the attributes and behaviors associated with a concept.
  - c. Explain how a computer model illustrates a given concept.

## Prep

- Choose a concept with clear attributes and behaviors, such as a day and night cycle, a traffic light, a plant growing with water, or a predator and prey.
- Sketch what a simple version might look like in the programming tool.

## Warm-up (3 minutes)

Show the globe or diagram. Ask, "What does this model show well? What does it leave out? Can it move or change?"

## Direct Instruction (4 minutes)

- Review models: simpler versions that keep what matters.
- Define computational model: a model that runs on a computer, so it can show change and respond to input.
- Define the two things to capture. Attributes: features that can be stored as variables, such as size, color, or amount of water. Behaviors: actions that follow rules, such as growing, moving, or changing color.
- Plan a traffic light together: attributes are the current color and a timer; the behavior is changing color in order after a set time.

## Guided Practice (9 minutes)

1. The student chooses a concept and lists its attributes and behaviors.
2. The student builds the model: a character or shape, a variable for one attribute, and a rule for one behavior.
3. Run the model and compare it with the real thing.
4. Adjust one rule to make it more accurate.

## Independent Practice / Quick Check (4 minutes)

The student demonstrates the model and explains which attributes and behaviors it shows, how it illustrates the concept, and one thing it leaves out.

Look for:
- The model has at least one attribute and one behavior.
- The model runs and changes over time or with input.
- The student connects the model to the real concept and names a limit.

## Differentiation

**For students needing support**
- Model the traffic light using the plan made together.
- Provide a starter project with the character in place.

**For students ready for more**
- Add user input that changes an attribute, such as a slider or key for water.
- Add a second attribute that affects the behavior.

## Extensions

- Show the model to someone and ask what they learned from it.
- Compare your model with an animation or simulation of the same concept online.

## Notes for Parent/Instructor

- Grade 3 made physical models. Grade 4 makes one that runs.
- Naming what the model leaves out is part of understanding models.
