**Standards covered (2024 Virginia Computer Science SOL)**

- **3.AP.1** The student will apply computational thinking to design algorithms to extend patterns, processes, or components of a problem.
  - c. Design an algorithm to extend either a pattern, process, or component of a problem.

## Warm-up (3 minutes)

Build a staircase of blocks: 1, 3, 5. Ask, "What comes next? What about the tenth step? Would you want to build every step to find out?"

## Direct Instruction (5 minutes)

- Explain: "To extend something is to make it continue. An algorithm can describe how a pattern keeps going so anyone can continue it."
- Write the algorithm for the staircase: 1. Start with 1 block. 2. Add 2 blocks to the last step to make the next step. 3. REPEAT step 2.
- Test it by following it for two more steps.
- Show the same idea for a process: a watering routine for one plant can be extended to a row of plants by adding "move to the next plant" and "repeat until the last plant."

## Guided Practice (6 minutes)

1. The student writes an algorithm to extend a color pattern on grid paper.
2. Swap roles: you follow the algorithm exactly for four more steps.
3. Extend a process together: turn "address one invitation" into an algorithm for addressing ten.
4. Ask, "What did we add to make it continue?"

## Independent Practice / Quick Check (5 minutes)

Show a new growing pattern (2, 4, 8). The student designs an algorithm that extends it and tests it for three more steps. Then the student extends a one-time process of their choice so it handles many items.

Look for:
- The algorithm names a starting point, a rule, and a repeat.
- Following the algorithm exactly produces the correct next steps.
- The student can extend a process as well as a number pattern.

## Differentiation

**For students needing support**
- Use a repeating pattern before a growing one.
- Provide the frame: Start with ___. Each time, ___. Repeat.

**For students ready for more**
- Write an algorithm with a stopping rule, such as "repeat until there are more than 50."
- Extend a pattern that changes in two ways at once.

## Extensions

- Write an algorithm that extends a bead or tile design and have someone follow it.
- Find a process at home that could be extended to do more with one extra step.

## Notes for Parent/Instructor

- Lesson 1 found patterns. This lesson turns a pattern into instructions.
- Following the student's algorithm literally is the test of whether it is complete.
