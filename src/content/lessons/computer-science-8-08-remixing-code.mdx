**Standards covered (2024 Virginia Computer Science SOL)**

- **8.AP.4** The student will incorporate work from others into programs and projects.
  - c. Use and remix code from other projects within a programming project and provide proper attribution.

## Prep

- Find a small project or code example whose license or terms allow reuse and remixing.
- Read it yourself so you can help the student understand it.

## Warm-up (3 minutes)

Ask, "Is using someone else's code cheating? When is it, and when is it not?"

## Direct Instruction (4 minutes)

- Draw the line: reuse is normal practice when the code's license or terms allow it, the source is credited, and you understand what you are using. It is not acceptable when the terms forbid it, when it is passed off as your own, or when an assignment requires original work.
- Teach the process: read the license or terms, read and understand the code, run it alone, adapt it, test it within your project, and attribute it.
- Show attribution for code: a comment where the code appears naming the author, source, license, and what you changed.
- Explain remixing: adapting the code to your needs, not copying it unchanged.

## Guided Practice (9 minutes)

1. The student reads the borrowed code and explains what it does.
2. Run it on its own.
3. Remix it: change it to fit the project.
4. Integrate it, test it, and add the attribution comment.

## Independent Practice / Quick Check (4 minutes)

The student demonstrates the integrated feature, shows the attribution, and explains which parts are borrowed, which are changed, and which are original.

Look for:
- The source's terms permit the reuse.
- The student understands the borrowed code.
- Attribution states source, author, license, and changes.

## Differentiation

**For students needing support**
- Remix a short code example of a few lines.
- Read the code together.

**For students ready for more**
- Remix code from two sources and resolve the conflicts between them.
- Contribute an improvement back to the original project, if it accepts contributions.

## Extensions

- Study how a large open-source project credits its contributors.
- Add a license and credits file to your project.

## Notes for Parent/Instructor

- Understanding borrowed code before using it is part of using it responsibly.
- Many assignments limit outside code. Checking the rules is part of the lesson.
