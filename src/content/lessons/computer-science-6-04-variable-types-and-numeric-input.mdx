**Standards covered (2024 Virginia Computer Science SOL)**

- **6.AP.2** The student will plan and implement algorithms that include conditional control structures and collection of numeric data using a block-based or text-based tool.
  - b. Read and write programs that initialize Boolean, integer, and decimal number variables.
  - c. Read and write programs that collect numeric data from users.

## Prep

- Decide which programming tool to use this year and try it. In a text-based language, check how input is converted from text to a number.
- Write a three-line sample that sets one variable of each type.

## Warm-up (3 minutes)

Ask, "What is different about these three facts: you have 3 pets, the temperature is 71.5 degrees, and the door is locked?"

## Direct Instruction (5 minutes)

- Define the three types. Integer: a whole number. Decimal number, often called a float: a number with a fractional part. Boolean: a value that is either true or false.
- Review initializing: giving a variable its starting value.
- Show your sample and read it aloud.
- Explain numeric input: input usually arrives as text and must be treated as a number before calculating. Show how your tool does this.
- Explain why type matters: counting needs integers, measuring needs decimals, and yes or no facts need Booleans.

## Guided Practice (8 minutes)

1. The student reads a short program you provide and states each variable's type and value.
2. The student writes a program that initializes one variable of each type and displays them.
3. Add a prompt that collects a number from the user and stores it.
4. Use the number in a calculation and display the result.

## Independent Practice / Quick Check (4 minutes)

The student writes a program that asks for two numbers, such as length and width, calculates a result, and sets a Boolean based on it, such as whether the area is over 100.

Look for:
- Each variable is initialized with a value of the right type.
- Numeric input is collected and used in a calculation.
- The student can read a program and name its variable types.

## Differentiation

**For students needing support**
- Work with integers only, then add decimals.
- Provide a starter program to modify.

**For students ready for more**
- Handle a user who types something that is not a number.
- Explain what happens when an integer is divided and the result is not whole.

## Extensions

- Write a tip calculator or a unit converter.
- Read a short program from a tutorial and identify its variable types.

## Notes for Parent/Instructor

- Block-based tools hide types more than text-based ones. Name them aloud either way.
- Whichever tool you choose, stay with it through the Grade 6 lessons.
