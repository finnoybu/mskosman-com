**Standards covered (2024 Virginia Computer Science SOL)**

- **6.AP.2** The student will plan and implement algorithms that include conditional control structures and collection of numeric data using a block-based or text-based tool.
  - a. Create a decision tree diagram to illustrate the decision-making process.

## Warm-up (2 minutes)

Play a quick round of twenty questions. Ask, "How did each answer narrow things down?"

## Direct Instruction (4 minutes)

- Define decision tree: a diagram that starts with one question and branches by each answer until it reaches an outcome.
- Name the parts: the root question, branches for answers, further question nodes, and leaves, which are outcomes.
- Model a tree for a shipping fee: Is the order over 50 dollars? If yes, free. If no, is the customer a member? If yes, 2 dollars. If no, 5 dollars.
- Connect it to code: each question node is a conditional, and a question below another is a nested conditional.

## Guided Practice (7 minutes)

1. The student chooses a decision, such as which activity to do after school.
2. Write the questions on sticky notes and arrange them.
3. Draw the tree with labeled branches and outcomes.
4. Trace two different paths from root to leaf.

## Independent Practice / Quick Check (4 minutes)

The student creates a decision tree for a process you describe in words, such as a library's rules for late fees, and checks that every path ends in an outcome.

Look for:
- Each question has clearly labeled branches.
- Every path ends in an outcome.
- The order of questions makes sense.

## Differentiation

**For students needing support**
- Use yes or no questions only.
- Provide the root question.

**For students ready for more**
- Rearrange the tree so that fewer questions are needed on average.
- Write the tree as pseudocode.

## Extensions

- Make a decision tree for troubleshooting a device.
- Find a decision tree or flowchart in a manual or guide.

## Notes for Parent/Instructor

- Keep this tree. Lesson 6 turns it into a program.
- Asking the most dividing question first makes a tree shorter.
