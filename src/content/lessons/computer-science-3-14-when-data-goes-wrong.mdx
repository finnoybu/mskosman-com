**Standards covered (2024 Virginia Computer Science SOL)**

- **3.DA.1** The student will gather, store, and organize data to evaluate trends and identify patterns using a computing device.
  - c. Examine a labeled dataset to identify potential problems within the data.
  - d. Discuss how data discrepancies or problems impact predictions and results.
  - e. Draw conclusions and make predictions based on observed data.

## Prep

- Prepare a small labeled table of 10 rows, such as children's names, ages, and heights. Plant four problems: a missing value, an impossible value (age 80 in a list of children), a duplicate row, and a value in the wrong column.

## Warm-up (3 minutes)

Say, "I measured everyone in the family. The average height is 9 feet." Ask, "Do you believe me? What might have gone wrong?"

## Direct Instruction (5 minutes)

- Define dataset: a collection of data. A labeled dataset has headings that say what each column means.
- Name common problems: missing data, values that are impossible or far from the others, duplicates, data in the wrong place, and typing errors.
- Define discrepancy: something that does not match or does not make sense.
- Explain the effect: "If the data is wrong, the results and predictions built on it will be wrong too." Show how one impossible value changes the largest value or the total.

## Guided Practice (6 minutes)

1. The student examines the prepared dataset and highlights each problem.
2. For each one, ask, "How could this change what we conclude?"
3. Decide what to do about each: fix it, remove it, or check the source.
4. Open the student's own spreadsheet and check it the same way.

## Independent Practice / Quick Check (4 minutes)

Using the corrected dataset, the student states one conclusion and one prediction. Then ask, "What would your conclusion have been if we had not found the problems?"

Look for:
- The student finds most of the planted problems.
- The student explains how a problem would change a result.
- The conclusion and prediction fit the corrected data.

## Differentiation

**For students needing support**
- Plant two obvious problems.
- Read each row aloud and ask, "Does this make sense?"

**For students ready for more**
- Decide whether an unusual value is an error or simply unusual, and how to find out.
- Plant errors in a dataset for you to find.

## Extensions

- Check a real list, such as a contact list or a score sheet, for errors.
- Talk about a time a wrong number caused a mistake in real life.

## Notes for Parent/Instructor

- Not every surprising value is an error. Asking "How could we check?" is the right instinct.
- This lesson can be done on paper or in the spreadsheet.
