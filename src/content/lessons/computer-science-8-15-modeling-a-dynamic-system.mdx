**Standards covered (2024 Virginia Computer Science SOL)**

- **8.DA.1** The student will create computational models to simulate events or represent phenomena.
  - a. Compare and contrast the use of computational models and simulations to analyze patterns and replicate phenomena.
  - b. Design and create complex computational models that simulate dynamic systems (abstraction), incorporating multiple variables and interactions.

## Prep

- Choose a dynamic system with two or more interacting quantities, such as predators and prey, a spreading illness in a population, savings with interest and spending, or water in a tank with inflow and outflow.

## Warm-up (3 minutes)

Ask, "If the number of rabbits on an island doubles, what happens to the foxes? And then what happens to the rabbits?"

## Direct Instruction (5 minutes)

- Distinguish the terms. A computational model is the representation: the variables and the rules that relate them. A simulation is running the model over time, often many times with different inputs, to see what happens.
- Compare their uses: a model is analyzed to understand structure and patterns; a simulation replicates a phenomenon to explore outcomes that would be slow, costly, or unsafe to try.
- Define dynamic system: one that changes over time, where variables affect each other.
- Model the design steps: choose the variables, define how each one changes per time step, define the interactions, set the starting values, and state the assumptions. This is abstraction.

## Guided Practice (9 minutes)

1. The student draws a system diagram with the variables and arrows showing what affects what.
2. Write the rule for each variable's change per step.
3. Build the model with at least three variables and one interaction.
4. Run the simulation for 20 or more steps and chart the result.

## Independent Practice / Quick Check (3 minutes)

The student explains the model: its variables, interactions, and assumptions, and describes the difference between the model and the simulation they ran.

Look for:
- Model and simulation are distinguished.
- The model has multiple variables with at least one interaction.
- Assumptions are stated.

## Differentiation

**For students needing support**
- Model a system with two variables and one interaction.
- Build from a starter spreadsheet.

**For students ready for more**
- Add a feedback loop where a variable affects itself through another.
- Add randomness and run the simulation several times.

## Extensions

- Explore a published simulation and identify its variables and interactions.
- Model a system from science class.

## Notes for Parent/Instructor

- The system diagram comes before any formulas or code.
- Keep the model for Lessons 16 and 18.
